#
# SPECIAL STATUSES (international_organization_special_statuses/):
#
#   cc_core_member:
#     - Full voting rights, can propose resolutions
#     - Parliament power: high
#     - Only City of Genoa at start
#
#   cc_trade_office:
#     - Full voting rights, can propose resolutions
#     - Enables special trade buildings in assigned sea region
#     - Gazaria (Black Sea) at start; Western Office (Atlantic) unlockable via law
#     - Extraterritorial — no land, only buildings
#
#   cc_state_bank:
#     - Full voting rights, can propose resolutions
#     - Can absorb (annex) Maone, turning them into "client" subjects
#     - Created via parliament resolution when debt >= 5000 or bankrupt
#     - Player can switch to play as the Bank
#
#   cc_maona:
#     - Junior voting rights in parliament
#     - Created via "Organize Expedition" parliament resolution
#     - Has charter timer (20-50 years)
